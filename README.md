# SlideImageViewer

一个以"看图"为唯一目标的极简图片浏览器：除系统标题栏外，整个窗口全部留给图片。

## 功能

- **格式支持**：jpg / jpeg / jfif / png / gif / webp / bmp / avif / svg / ico，
  其中 **GIF 和 WebP 动图原生播放**
- **连续平铺**：打开一张图后，同文件夹的所有图片按文件名顺序从左到右铺成一条"胶片"
- **水平图上下堆叠**：连续两张宽高比达到 4:3 的横图会上下叠放在同一列里，省出横向空间。
  可在右键菜单里关掉
- **滚轮自动播放**：滚动滚轮即开始自动播放（图片从右往左滚动），继续滚动可加速/减速，
  向上滚到负值即反向播放。速度表从 0 起步，所以第一次向下滚轮是 0.2x，一格 0.2x。
  没有循环，播放到文件夹末尾会自动停下
- **空格键**：暂停 / 继续自动播放
- **标题栏**同步显示当前图片名和进度，例如 `a_01.png (3/120) - SlideImageViewer`
- **鼠标指针自动隐藏**：自动播放时鼠标停在图片区域不动满 5 秒就把指针藏起来；
  一动、一点击，或者移到图片区域外（底部状态栏、右键菜单）就立刻显示。
  规则作用于整个窗口（状态栏和右键菜单除外），指针停在任何元素上都生效
- **窗口状态记忆**：第一次打开默认最大化；之后记住上次关闭时的位置、大小和是否最大化，
  下次打开按原样恢复
- **极简界面**：除系统标题栏外全部留给图片
  - 右键菜单：打开图片/文件夹、上一张/下一张、播放控制、堆叠开关、在资源管理器中定位、全屏、退出
  - 鼠标移到窗口底部浮现半透明状态栏：文件名、可拖动进度条（显示当前图片在文件夹中的位置）、张数、播放速度

## 操作

| 操作 | 效果 |
| --- | --- |
| 滚轮 ↓ / ↑ | 开始播放并加速 / 减速（减到负值反向），一格 0.2x |
| 空格 | 暂停 / 继续 |
| ← / → | 上一列 / 下一列 |
| Home / End | 第一列 / 最后一列 |
| + / − | 加速 / 减速 |
| 鼠标左键拖拽 | 手动平移浏览 |
| 拖动底部进度条 | 跳到某一张 |
| F11 / Ctrl+O | 全屏 / 打开图片 |
| 拖入文件或文件夹 | 直接打开 |
| 右键 | 菜单 |

注：开启堆叠后，一次"翻页"的是一列（可能含上下两张图），所以状态栏张数会显示成 `8-9 / 10` 这样。

## 运行

```bash
npm install                                  # 首次
npm start                                    # 启动
npm start -- "X:\某文件夹\图片.gif"           # 直接打开指定图片
```

## 打包

```bash
npm run build
```

产物在 `dist/` 下，两个版本都是**未压缩目录**的形式，启动很快：

- `SlideImageViewer-<版本>-setup.exe` —— 安装版（可选安装目录，带开始菜单和桌面快捷方式）
- `SlideImageViewer-<版本>-win-x64.zip` —— 解压即用版（解压后直接运行 `SlideImageViewer.exe`）

不做单文件便携 exe：那种形式每次启动都要先把自己解压到临时目录，打开很慢，对看图软件是致命伤。

## 测试

全部测试都在**不会打扰你**的窗口里进行（隐藏窗口，或"1% 不透明度 + 不进任务栏 + 不抢焦点 +
不接受鼠标"的隐形窗口），不会弹出任何东西。

```bash
npm run smoke            # 功能自检 37 项：加载、分块、堆叠、定位、调速、暂停、跳转、
                         #   边界停止、标题栏更新、指针隐藏、渲染池范围、大文件夹打开速度
npm run verify-sizes     # 图片尺寸解析交叉验证（拿 Chromium 自己解码的结果当标准答案）
npm run check-title      # 标题栏在自动播放时确实跟着更新
npm run check-cursor     # 鼠标指针自动隐藏（真实鼠标事件 + 真实 5 秒等待，
                         #   并且检查指针样式真的作用到了元素上，不只是类名）
npm run check-window     # 窗口状态记忆：保存 → 恢复
npm run bench            # 性能测量：同屏有多少张图在解码播放、每帧耗时、DOM 变动量
npm run bench-open       # 性能测量：打开大文件夹各阶段耗时（参数为文件数量）
npm run shot             # 截图，用来肉眼检查界面效果（--out 路径 图片路径）
```

测试素材由脚本生成，需要时先跑：

```bash
npm run gen-images       # 10 张测试图（含一张两帧 GIF 动图）
npm run gen-anim         # 40 张真正的动画 WebP
```
